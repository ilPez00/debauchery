## Spec ambiguities resolved

1. **Zig sha256 pin**: Spec says "record the observed hash in docs/INSTALLER.md on first successful fetch; until then warn that the hash is unpinned". Implemented: 14-display-manager.sh warns on first fetch, TODO comment in code to record after verification.

2. **Preseed ISO sha256**: Spec says "URL + sha256 in the script header, verify". Used placeholder in test-install-vm.sh header with comment to replace after first verified fetch.

3. **Autologin config rendering**: Spec says "render the autologin lines into the config (auto_login_user/session/service='ly-autologin')". Implemented: sed replacement of nil values in existing config when --autologin flag given.

4. **Container mode detection**: Spec says `[ -d /run/systemd/system ]` false → skip ALL systemctl calls. Implemented in lib-installer.sh `systemd_available()` and used in all scripts.

5. **Subuid allocation**: Spec says "parse existing entries' max end; start 100000 if empty". Implemented: while loop checking /etc/subuid for next free 65536 range.

6. **Handoff repo copy**: Spec says "if the repo dir is not owned by the target user, cp -a it to /home/U/debauchery and chown -R U:U". Implemented in bootstrap.sh with stat check.

7. **Modules.conf check commands**: Spec provides exact check strings. Used verbatim with proper escaping for $ in dpkg-query format string.

8. **Module args for base/dm**: Spec says "pass --user '$SUDO_USER' to base/dm when invoked via install.sh (bootstrap passes it explicitly)". Implemented in install.sh module_args.

9. **Bootstrap dry-run as any user**: Spec says "--dry-run: works as any user, prints the full ordered plan". Implemented: dry-run exits early before root check.

10. **Ly build skip condition**: Spec says "If command -v ly AND /etc/ly/config.lua exists → log 'ly present', skip build". Implemented exactly.
