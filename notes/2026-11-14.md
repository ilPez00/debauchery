# 2026-11-14 — Omarchy contract layer + installer (air)

**Status: applied, verified.** `./install.sh doctor` → exit 0, 0 fails, 0 warns.

## What this session was for

`PLAN.md` proposed two ways to get Omarchy's feel on Debian: port a kit
(Options A/C) or stay on DMS. Both port kits carry `[SYSTEM]` steps — a
`/etc/pam.d` drop-in, masking `xdg-desktop-portal-hyprland`, `/etc/fastfetch` —
which are the documented ways to break screen locking and screen sharing on a
working session. Measured host state first, then built the third option: keep
DMS, and port Omarchy's **interface**.

## Verification (the numbers, not the impression)

```
./install.sh doctor                 → exit 0, fails: 0 warns: 0
./install.sh doctor --json          → valid JSON, same counts
./install.sh binds omarchy|niri     → "config ok" twice, then left on niri
./scripts/08-arch-bridge.sh --check → 39 map entries, no FAILED
./scripts/11-omarchy-shims.sh --check → 23/23 verbs, exit 0
bash -n on every script; zsh -n on the zsh snippets → silent
zsh -c 'source ~/.config/debauchery/aliases.zsh; alias ar' → ar=omarchy-arch
```

Left on `niri` on purpose: switching the live keymap mid-session costs muscle
memory for no measurable gain. `./install.sh binds omarchy` is one command away.

## Bugs found by running the code (not by reading it)

| Bug | Fix |
|---|---|
| native module with script `-` was checked as a missing file | `run_module` handles `-` before the file test |
| `install.sh set KEY=VALUE` lost the value — arg parsing shifted past it | parse flags anywhere, keep the rest in `REST[]` |
| `check_ok` swallowed the module loop's stdin | `bash -c "$1" </dev/null` |
| `$VERSION` was clobbered by `. /etc/os-release` (prints `13` as a version) | renamed to `DBVERSION` |
| `backup-desktop.sh` failed on a second run (`cp` into an existing dir) | skip if already backed up |
| `bind = SUPER, J, togglesplit` — Hyprland 0.55 rejects the dispatcher | `layoutmsg, togglesplit` |
| shim `--check` read unbound `$4` under `set -u` | default it |
| optional deps (`tesseract`, `wf-recorder`) failed `--check` | reported as `missing (optional)` |
| `doctor --json` printed the human rows too | `log`/`warn` are silent in JSON mode |
| `bind = CTL ALT, M` — typo, Hyprland ignores the whole line | `CTRL ALT` |

## Deviation from PLAN.md worth remembering

`PLAN.md` §8 said "keep niri as the default session while testing Hyprland".
That did not survive contact: ly has auto-logged into Hyprland since 2026-11-12,
and `STATE.md` says so. `PLAN.md` now records the outcome instead of the
intention. Rule for future sessions: `STATE.md` is status, `PLAN.md` is options,
`./install.sh status` is the executable truth.
